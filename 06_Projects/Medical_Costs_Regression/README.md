# 💰 Medical Costs Regression Project

## 📋 Project Overview

This project implements a comprehensive regression analysis to predict medical costs using various regression techniques. The study explores different approaches to model the relationship between patient characteristics and medical expenses.

### 🎯 Objectives

- Predict medical costs based on patient demographics and health indicators
- Compare different regression models and their performance
- Identify key factors influencing medical expenses
- Demonstrate practical application of statistical regression techniques

## 📊 Dataset Features

The analysis considers multiple patient attributes:
- **Demographics**: Age, gender, geographic region
- **Health Indicators**: BMI (Body Mass Index), smoking status
- **Family Information**: Number of dependents
- **Target Variable**: Medical costs (charges)

## 🔬 Regression Techniques Applied

1. **Simple Linear Regression**
2. **Multiple Linear Regression**
3. **Polynomial Regression**
4. **Other Advanced Regression Methods**

## 📁 Project Files

## 📈 Key Findings

The analysis reveals important insights about factors affecting medical costs:
